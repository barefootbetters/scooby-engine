The container dl.metadata-panel and its styling are core theme CSS (D-24782). why: this repo's pages carry only layout+title front matter, so Type, Status and Tags render only on a page that sets them — forward-compatible with LA's field schema, a no-op on today's pages. "Last reviewed" always renders: from the page's last Git commit date and time (.Lastmod, with enableGitInfo = true in hugo.toml), or from an explicit last_reviewed / last-reviewed front-matter value when a page sets one. The Git source needs the CI checkout's full history (ewiki.yml fetch-depth: 0); without it .Lastmod falls back to the file's mod time. A Git commit carries only a numeric UTC offset, no zone name, so formatting with "MST" prints "-0800". Resolving that offset to a name needs tz data, which the Hugo build binary on the CI runner lacks (it silently no-ops, leaving "-0800"); only a machine with tz data would show "PST". So the abbreviation is derived from the offset itself — Jeff authors these commits in Pacific, so -0800 is PST and -0700 is PDT — which needs no tz data and renders identically on the runner and locally. Any other offset falls back to its numeric form. It is a pure string map, so the determinism gate (Invoke-WikiGates.ps1 gate 3) stays green. */ -}}
