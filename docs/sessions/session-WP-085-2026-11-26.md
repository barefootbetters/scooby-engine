**Local only, never staged:** `/root/.gradle/gradle.properties`, the identity
`res` dir, build outputs, captures that show the TV's serial or LAN address,
`P:\games\**`, `P:\scooby-engine\**`.

**Forbidden:** `engines/terraglyph/**` and every other fork path; the product
name or package id anywhere public; game data, signing keys or credentials in
any repo; creating `barefootbetters/tv-test-packages` without Jeff's go;
changing D0–D4.

**You MUST:**

- **Inject the identity (Q1).** `applicationId findProperty('tvAppId') ?:
  "org.scummvm.scummvm"`; label, icon and banner via `manifestPlaceholders`,
  with today's values as defaults; `tvAppResDir` is added to `res.srcDirs` only
  when it's set. `namespace` stays `org.scummvm.scummvm`. A build without the
  properties must still produce plain ScummVM.
- **Keep the advanced mode out of the release build (D4)** with build-type
  source sets: the real classes in `backends/platform/android/advanced/`
  (debug only), a same-named stub in `advanced-stub/` (release). EC-008 Step 3
  captures `apkanalyzer dex packages --defined-only` on the release APK (no
  `org.scummvm.scummvm.advanced`) and a `strings` grep of its dex for the
  manifest-URL sentinel (count 0).
- **Do the download, verify and extract in Java.** Download to
  `getFilesDir()/packages/.staging/`, refuse on SHA-256 mismatch, extract to
  `getFilesDir()/packages/<id>/<version>/`, then add through ScummVM's own
  `--add --path=<dir> --recursive --no-exit`, restarting the ScummVM thread as
  `onNewIntent` does. On update, unpack beside the old version and switch the
  game's `path` only after verification.
- **Allow only data.** Refuse zip entries ending `.so`, `.dex`, `.jar` or `.apk`,
  files with ELF or dex magic, and any entry whose canonical path escapes the
  package dir (zip-slip). Load nothing from a package.
- **Make the downloader host-independent:** any HTTPS URL from the manifest, no
  hard-coded host (D3).
- **Check each commit:** run `git diff --cached --name-only` against the
  allowlist, and grep the staged diff for the private name and id, before every
  commit in every repo.
- **Capture every EC-008 box:** a logcat excerpt, command output or screenshot.
  Jeff's live confirmations are quoted as his, never paraphrased into a
  capture.
- **Fix before moving on:** a failed milestone check is fixed on the branch
  before the next milestone starts.
- **Run the ewiki gates** for the public docs with the private worktree
  junctioned as `_private`, checking every link and anchor you add. Remove the
  junction with `(Get-Item _private).Delete()`, never a recursive delete.

**Top risks (from the pre-flight), as instructions:**

- Name or id leak: grep before every commit; review PR text before opening.
- Executable download: the extractor refusals above; §Result's code-review note
