## After execution — lessons learned

**Lesson: a placement that is already a requires object keeps its own cursor; don't re-claim it with the rollover.** `OBJ_P07_ROYAL_GALLERY_MIRROR` is `ID=requiresobject` in `object.ini`, answering the found mirror (`requiredanim=ANIM_CURSORHAND_MIRROR`). Claiming it as a requires object and setting `claim.required` to `ANIM_CURSOROPEN` (the original's *rollover*, `+0x70`, not its *required* cursor, `+0x5C`) made the found mirror fall on nothing (`Global.WRONGS_`). The fix leaves the default path to build it with its own `requiredanim=`, and `enter()` only sets its animation and its open-hand rollover.

**Lesson: a check's `findSprite` matches the object's name, not the sprite's label.** The first build missed the mirror because `enter()` looked it up by `getLabel`, so it never stopped the looping requires object; the reference's `mode 0` met the engine's `mode 1`. The drawbridge's `findSprite` matches `getObjectName`.

**Lesson: a shared room sub-object is reused, not re-ported.** The gallery's Jester is the room of doors' `JesterControl` embedded at `+0xC8`; the port includes it by value and calls its `enter`/`tick`/`click`, rather than tracing it again.

**Scope note:** one fork commit of 7 files staged by name: the two classes and their check in new files, a factory line, the module entries, the check's declaration and its call.
