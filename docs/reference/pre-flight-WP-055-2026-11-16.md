## After execution — lessons learned

**Lesson: read what the tree does after the walk.** `0x431190` deletes every sprite marked done; "paused" was the wrong reading of `+0x30` in WP-054.

**Lesson: let the reference pick the test inputs.** With the cels decoded from the art, the reference found the throws that really hit (the ghost from x 232 to 321, Fred only once he is in the pies' span). The check then drives those, and the reference predicts every tick.

**Lesson: check the sound model when a room waits for a sound.** The chime ends the room, and the tock played in the same tick. The fork's handle per file had never been tested against two effects at once.

**Lesson: verify an argument's order in the disassembly.** Ghidra showed the splat counter's increment before the format call; the old value was pushed first, and the disc's `Splat.0` to `Splat.4` agree.

**Scope note:** one fork commit of 9 files staged by name. Beyond the room: the tree walk and its sweep, hit-test helpers and a step past the last in `room.{h,cpp}`, and a handle per sound effect in `sound.{h,cpp}`.
