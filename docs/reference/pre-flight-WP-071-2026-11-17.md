## After execution — lessons learned

**Lesson: a room's opening waits 100 ticks; a check must let it play before clicking.** Skipping the scene found nothing to skip, because the opening hadn't started, and input was still held. The check now ticks each room until its opening is over and input is free.

**Lesson: count a timed action from the tick it starts in.** Velma's take begins in the tick the rope's line ends. A count from the next tick, with a test that skipped tick 0, lost the first tick and the end.

**Lesson: an `int *` index is four bytes.** The treasury writes the game's index `+0x42`, which is byte `+0x108`, `FinalClue`; read as a byte offset it names nothing.

**Scope note:** one fork commit of 7 files staged by name: the four classes and their check in new files, a factory line, the module entries, the check's declaration and its call.
