## After execution — lessons learned

**Lesson: read which field a test reads.** A clickable has the sequence it plays (`+0x54`) and its state, the next one (`+0x60`). Street 3 and Street 1 test the state, so their scenes come one letter early. WP-033 had read it as the playing sequence.

**Lesson: a new virtual can capture a peer's method.** `RoomClass::leave()` would have made OptionsRoom's own `leave()` an override. `-Woverloaded-virtual` caught it through SignInRoom's.
