## After execution — lessons learned

**Lesson: find every class a story beat touches before claiming it.** "The safe" turned out to be one feature of the vault's class, beside two more, and the bank has five classes. Listing the vtables that reference the beat's strings, and the rooms the factory builds them for, set a scope that could be finished, with the rest named for later packets.

**Lesson: a check that clicks a clickable has to turn the ghost off.** The ghost takes a clickable's click 1 time in 30. This packet's dust check turns it off; one run of another check showed what happens without that.

**Lesson: a reference should follow the trace, even where the engine had it otherwise.** The chase reference had every sprite hit by its polygon, copied from the fork's default. When the other session fixed the default to the trace, the reference had to change too; written from `0x430D60` in the first place, it would have caught the default.

**Scope note:** one fork commit, 7 files staged by name. The shared files got the factory line, the module entry, and `RoomScript::setClickable`, told to the other session.
