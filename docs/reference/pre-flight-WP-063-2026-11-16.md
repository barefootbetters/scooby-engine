## After execution — lessons learned

**Lesson: size the room's pair before taking it as one step.** The audit lists the dining room with `ROOM_Maria`; tracing both showed her game is a set piece of its own. Splitting it kept this WP to what one check and one live run can cover.

**Lesson: read the room's layers before trusting a class's layer.** The class builds under the second layer, which this room doesn't have; the reference read the layer table from the art rather than assuming it.

**Scope note:** one fork commit of 9 files staged by name: the room and its check in new files, two claim kinds in `room.h` and `room.cpp`, a factory line, the module entries, the check's declaration and its call.
