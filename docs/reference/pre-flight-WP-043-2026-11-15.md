## After execution — lessons learned

**Lesson: identical objects are told apart by their sequences.** The four levers and the sandbags share one object name each; the class reads the digit in each one's sequence (the last character, or the sixth from the end for `SANDBAG2_DROP`). A hook that passes only the object name can't serve them, so the clickable's callback passes the sprite.

**Lesson: a check's direct click skips the hit test.** `clickClickable` registers a click without testing the sprite's hit type, so it can't show that a switched-off lever ignores clicks. The check reads the hit types instead, and the live run's real click hit the lever.

**Scope note:** one fork commit of 7 files staged by name, then a one-line comment fix. Besides the factory line and the module entry, the shared files got the clickable's callback.
