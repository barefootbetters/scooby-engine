## After execution — lessons learned

**Lesson: an exit handler can keep the gang without a word of its own.** The dark tunnel's handler never calls the default one, so its way out is only a line; nothing in `object.ini` says so. Reading each room's +0x24 before trusting its exits is what showed it.

**Lesson: a requires object can answer to the arrow.** The crate's `requiredanim` is ANIM_CURSORARROW, so a plain click is the right item; the event's success flag carries it.

**Scope note:** one fork commit, 5 files staged by name. The shared files got the factory line and the module entry.
