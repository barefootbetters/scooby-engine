## After execution — lessons learned

**Lesson: a "packet" named after a whole area needs sizing first.** "The story rooms" are about 65 KB of class code per title. Measuring each class's overridden functions before writing the WP gave the split: groundwork and one room here, a few rooms per packet after.

**Lesson: scenes run at the clips' pace, not the ticks'.** A check that ticks as fast as it can measures a scene's length in wall-clock time, not game time. The checks name each scene as it starts and skip it; the live test drives Escape (`key 27`).

**Lesson: read the section argument, not the call.** WP-028 put room classes' keys in `Game`; `0x4376E0` passes the room object's name. The profile table now says so.
