## After execution — lessons learned

**Lesson: a second decoder makes a reference even where pixels can't match.** `ffmpeg` decodes Bink independently. Exact frames differ by YUV-to-RGB rounding, but frame counts, lengths and mean colours pin down a correct decode: 98 movies agree, with no colour more than 2 levels apart.

**Lesson: test damaged input, even through an upstream decoder.** A truncated movie hung `Video::BinkDecoder` inside a call, where no watchdog in the engine loop could reach it. The fix was a cheap header check before opening, confirmed against all 98 genuine files first.

**Lesson: count from the listing, not from memory.** The first draft said 43 and 58 movies; the census says 42 and 56. Corrected before commit.

**Scope note:** the lock held. One fork commit, staged by name. The scratch game folder was deleted, and the ISOs were dismounted. The other session confirmed it wasn't working on movies before this WP started.
