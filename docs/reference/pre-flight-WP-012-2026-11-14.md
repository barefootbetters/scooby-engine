## After execution — lessons learned

**Lesson: test against the mounted disc, not the cache.** `tools/exes/` flattens each disc into one directory and renames Case File #1's executable to `Scooby.exe`. Detection depends on the real directory layout and file names, so only the mounted ISOs could test it. All seven mount without admin rights.

**Lesson: game ids are shared across engines.** `--list-games` lists only the engines that are built, but bare-name lookup on the command line searches every detection plugin, and at the pin all of them are built. `phantom` and `jinx` were taken. Grep `engines/*/detection*` for a candidate id before using it.

**Lesson: a `timeout` around `scummvm.exe` under MSYS2 does not stop a running engine.** The engine window stayed open past the timeout until `Stop-Process`. Starting a game for a check needs an explicit kill.

**Scope note:** the lock held. The fork change is one commit under `engines/scooby/`. The ISOs were mounted read-only and dismounted afterwards; nothing was copied out of them.
