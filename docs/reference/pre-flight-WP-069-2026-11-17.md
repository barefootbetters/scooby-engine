## After execution — lessons learned

**Lesson: a check's room request carries over between its blocks.** The rise block's loop runs until a room is asked for, and the first arena's block had asked for one already, so the loop never ran and the line came out empty. Each block now starts with the request cleared, as the wait loops already did.

**Lesson: a random event in the class can swallow the check's input.** The pile's rattle marks the next event as the room's own, so a rattle while the player's click plays takes that click, in the game too. The check seeds the random source before each click instead of hoping for a quiet run.

**Lesson: read a field's offset from the trace before writing it down.** The draft said a queued click counts at `+0x70`; the decompile has `+0x80`, with `+0x70` one of the flags the clickable's tick tests.

**Scope note:** one fork commit of 10 files staged by name: the classes and their check in new files; in the shared files, queued clicks and the hook before the scene player, Big Head through a movie, the toolbar's open made public, a factory line, the module entries, the check's declaration and its call.
