## After execution — lessons learned

**Lesson: read a room's releases before porting its holds.** The close-up's tick frees input on every tick once the combination is in, so the combination's scene and Shaggy's take, both told to hold input, never do. Porting each hold as written would have blocked input the original leaves free.

**Lesson: start a live run mid-story from a profile.** `start_profile` loads a profile in the original's form and goes to its StartRoom, so the clue's visit could start with ICDouble met and `ArtifactsBuilt=1` without the artifact puzzle.

**Lesson: write PowerShell scripts with the file tool, not a bash heredoc.** The live script's `'\\'` reached the file as `'\'`, and PowerShell rejected the pattern; a parameter named `$profile` also shadowed PowerShell's own variable.

**Scope note:** the lock held: one fork commit with 3 files staged by name, all this session's. The class went in `chase_rooms` and its check in the chase check, so the shared files didn't change.
