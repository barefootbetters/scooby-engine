## After execution — lessons learned

**Lesson: a check has to tick where the real loop ticks.** The first live run crashed after the accusation's movie. The room comes back only to send the verdict, and still held its buttons from before the movie, whose sprites the reload had replaced. The real loop ticks the room once more before it changes, and that tick used them. The check had stopped short of that tick and passed. The room now clears its buttons on every entry, and the check ticks there too.

**Lesson: an untraced value can be answered by the code that reads it.** WP-004 found high bits in the lip sync and couldn't say what they were for. The character code ignores them; Big Head reads them as clue pictures. The answer was in the second reader, not the format.

**Lesson: read Ghidra's string labels as mangled.** `s_ANIM_BIG_HEAD_CLUES__s_d` is `ANIM_BIG_HEAD_CLUES_%s%d`, not `…_%s_%d`. Ghidra turns `%` into `_` in labels; the bytes settle it.
