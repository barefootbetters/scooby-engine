## After execution — lessons learned

**Lesson: save the original's own record, not a new format.** The original's profile is a plain INI file. Holding its text in the ScummVM save gives the original's format for free, keeps the story's keys before they're modelled, and lets an original `.sav` load.

**Lesson: write the reference's input as the original would, not as the engine would.** The import file used CRLF lines, a lowercase `yes`, `TRUE` and `on`, an empty value, and keys the engine has never seen. Every one of them exercises a read rule that a file the engine wrote itself never would.

**Lesson: commit, then rebase, when a teammate pushes first.** WP-025 landed on the same files mid-WP. A local commit and a rebase onto it went through cleanly, and nothing was force-pushed. The checks were then run again on the combined code.

**Scope note:** the lock held. One fork commit, staged by name. The live test wrote its saves to a scratch folder, not Jeff's ScummVM save folder.
