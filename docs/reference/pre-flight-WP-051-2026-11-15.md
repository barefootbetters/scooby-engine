## After execution — lessons learned

**Lesson: leaving a room can rewrite what the check just read.** The saloon's leave sets `ClickableOpen` from the hotspots' states, so keys read while the gang is still in the saloon are lost. Read a class's keys where the original reads them, outside its room.

**Lesson: a hit point belongs to a state.** A clickable's sequences can have their own polygons; take a click point with the state the run will meet.

**Lesson: a test profile needs every key its rooms read.** A missing count reads 0, as in the original, and can leave a room with nothing to do.

**Scope note:** one fork commit of 11 files staged by name. In the shared files: the character's state 0xE and set, the loader's buffer sprite, the idle timer's restart and two getters, the factory line and the module entry.
