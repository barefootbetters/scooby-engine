## After execution — lessons learned

**Lesson: trace the caller, not just the callee.** WP-001 had labelled the sprite tick, but its unit lived two calls up, in the game loop's `× 36 / 1000`. A vtable search on the function pointer found the tree walk, and the tree walk's only caller held the rate.

**Lesson: test a non-zero time, not just the start.** Tick 0 had already matched in WP-016. Hashing every room again after 37 ticks put 89 rooms (55 + 34) through different steps, which checks the countdown and the wrap.

**Lesson: default behaviour shows where scripts are missing.** The looping root-beer sign and piano bench are correct for the default path and wrong for the game. They are a concrete list of per-room overrides for Phase 4.

**Scope note:** the lock held. One fork commit, staged by name. The ISOs were dismounted afterwards, and the captures stayed in the scratchpad.
