## After execution — lessons learned

- **The live draw caught what the self-test could not.** The first wiring
  scanned object names for the six colours and the self-test passed — but it
  calls `claimPlacement("OBJ_WFR_BOTTLES")` with a hardcoded name, so it never
  exercises the real placements. The `start_room=ROOM_P30_WFR` run showed
  `0 bottles`: the six bottles are one `OBJ_WFR_BOTTLES` placement each, told
  apart by the colour in their **ANIM** (`getAnim`), not the object name; only
  Scooby and the wizard are the animated sub-class, and the counter is
  `OBJ_WFR_COUNTER`, not `COUNTERNUMBERS`. Always do the live draw — a green
  self-test on hardcoded names is not proof the room wires up.
- **The spinner's scene-position clock was the main porting judgment.** The
  original advances the spinner off a lip-sync scene's fractional playback
  position (`0x4358D0`), which the fork's scene player does not expose. Driven
  on a tick counter over the same position table (`0x46C5B0`) — the Maria-game
  idiom (WP-064). Reconstruction, not a bit-for-bit copy; the contract is what
  the self-test checks, the feel is for live play.
- **Every clip name from the trace resolved first try.** The inlined dotted
  names (`Wizards_Rule.Music`, the six colours, `WFR.Potion_%i`,
  `Wizards_Rule.Correct%i_1_NARRATOR`, `.Incorrect[/2/3]_1_NARRATOR`,
  `Knights.Glass_Breaks.1`) all probed 1 by prefix — the trace's strings were
  right, the WP-074 anim-vs-clip trap did not bite here.
- **The number collision — WP-082 was taken.** The WFR split off from WP-081 as
  "WP-082", but another session had meanwhile claimed WP-082 for the
  upstream-submission-prep brief (now on main). The claim check caught it before
  any work; the WFR took WP-083, and WP-081's forward references were renumbered
  on both open PRs (#139 docs, #6 fork). Always recheck main/branches/PRs at
  claim time — the number you reserved a session ago may be gone.
- The Ghidra "warm project holds Showdown" hazard (WP-076) held again: Phantom
  was re-used from the throwaway scratchpad project, read-only; the committed
  project was left untouched.
