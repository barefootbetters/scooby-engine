## After execution — lessons learned

**Lesson: rings queued on a clickable wait for it.** The original counts rings waiting on a clickable (`+0x80`) and plays each when the clickable is free. A direct click on a swinging clickable is lost in the fork, so the class keeps the count itself.

**Lesson: a check that ends sounds early changes their order.** Ending each note at once made the play-back end before its last ring, which then counted as the player's. The check now lets each note's ring go first, as real time does.

**Lesson: a callback and the room's tick share a frame.** The clickables tick before the room, so a request a callback makes is often answered before the frame ends. The reference has to expect the answer, not the request.

**Scope note:** one fork commit of 5 files staged by name. Besides the factory line and the module entry, no shared file changed.
