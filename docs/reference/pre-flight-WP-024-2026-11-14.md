## After execution — lessons learned

**Lesson: test without the host's mouse.** WP-023's live run took over the mouse of a machine in use. The engine's `test_script` plays input through the same handler as real events, and saves the screen itself, so live tests now run minimized and repeat exactly.

**Lesson: shared state needs a guard when a check reloads the room.** The first check run hung on an assert: the room was loaded again under a toolbar whose Scrappy was still talking, and stopping him touched a sprite index from the old room. The check now resets the inventory first, and stopping Scrappy checks the sprite is still his.

**Lesson: compare unchanged checks byte for byte.** The speech lock touches the scene player and the walk-off. "0 stuck" would have hidden a one-tick shift; the hashes of every exit, click and inventory line showed there was none.

**Scope note:** the lock held. One fork commit, staged by name. The other session was told before coding and asked to drop its duplicate WP-023.
