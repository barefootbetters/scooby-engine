## After execution — lessons learned

**Lesson: an unverified structural claim had been carried forward through two WPs.** WP-003 confirmed the `asset_count` offset, but the "`(start, end)` offset" reading of the 453 records had never been checked against the file size. A one-line check (is every `end` within the file?) would have caught it in WP-003. Format docs should mark each structural claim as checked across the file or checked on one sample. `tgifile-art.md` now does that for the WP-002 findings.

**Lesson: write the pre-flight before the session, even when another session starts it.** This copy was written after the decode had already landed. Next time, a session that starts from a brief should write the pre-flight before its first probe.
