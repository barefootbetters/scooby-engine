## After execution — lessons learned

**Lesson: compare a random choice as a set.** B's openings come from `rand() & 3`, which the reference can't draw in step with. Entering each room 40 times and comparing the set of openings seen checks both the rule and that every choice is reachable; a fixed opening shows as a set of one.

**Lesson: a live click has to wait for the opening.** The first live clicks in B6 and B5 did nothing: the base room holds input for the 100 ticks before an opening and while it plays. The run-off logic was fine; the script clicked too early. Clicking after the opening, both worked.

**Lesson: PowerShell variable names ignore case.** The live script's loop variable `$s` overwrote the scratch path `$S`, and every run failed to find its folder. Loop variables get names nothing else uses.

**Scope note:** the lock held: one fork commit staged by name, rebased onto the other session's `93cc76ae2f` before pushing. The shared files got the factory line, the `arrive` hook and the `exitTo` movie the other session agreed to; its setup check's chase lines change accordingly.
