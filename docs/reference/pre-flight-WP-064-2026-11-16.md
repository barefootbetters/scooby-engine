## After execution — lessons learned

**Lesson: a fixed seed turns a random game into a scripted one.** ScummVM's `random_seed` made two runs draw the same items, so the second could play the game to a win from the first's log.

**Lesson: test what holds for every draw.** The check never compares random values; it checks counts, ranges and that a balanced split exists, 40 times a level.

**Lesson: count a timer's ticks from where it is read.** `+0x24C` is compared before it counts down, so 72 means 73 ticks; WP-063's note had 72.

**Scope note:** one fork commit of 7 files staged by name: the game and its check in new files, a factory line, the module entries, the check's declaration and its call.
