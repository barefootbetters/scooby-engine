## After execution — lessons learned

**Lesson: read the mouse flags before porting a click.** Game `+0x20` has the button held, going down and coming up as separate bits (`0x4359C0`). The dial depends on the difference; earlier rooms read the release where the fork acts on the press.

**Lesson: an unknown sequence name is not a broken room.** The dial's time is a name built from the game's state. On a state with no time drawn, putting it in the claim made the room fail to load, and the setup check lost the room's line. Setting it with `startAnim` in `enter()` leaves the sprite blank, as the original does.

**Lesson: names in angle brackets need code formatting.** The site drops `<TYPE>`-style names outside code spans as HTML; three earlier ones had vanished from the built page unnoticed.

**Lesson: a toolbar item can't always come from `start_items`.** The broken clock has no toolbar sequence in `object.ini`; a profile's `[Inventory]` slot with its sequences puts it in the toolbar as the game does.

**Scope note:** one fork commit, 3 files staged by name, all this session's; the shared files didn't change.
